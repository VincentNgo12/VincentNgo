# Vincent Ngo — Personal webpage

A vintage, coffee-brown portfolio built with plain HTML and CSS. Responsive, keyboard accessible, and ready for GitHub Pages. No installation, build step, JavaScript, third-party fonts, or external image requests required.

## Preview

Open `index.html` directly in your browser, or run this command from the repository directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Commit these files to your repository. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select your branch and **/ (root)**, then save.

For the existing `VincentNgo12/VincentNgo` repository, the project URL will be `https://vincentngo12.github.io/VincentNgo/` once Pages is enabled and deployment completes. All local asset paths are relative, so both project and user Pages sites work.

## Make it yours

- `index.html`: elevator pitch, biography, project descriptions, and contact links.
- `styles.css`: coffee and parchment colors, typography, responsive layout, and print styles.
- `assets/favicon.svg`: matching initials icon.
- `.nojekyll`: serves the files directly through GitHub Pages.

The page works offline. The project, résumé, GitHub, LinkedIn, and email links open their respective external destinations when used.
