# Vincent Ngo — Personal webpage

A vintage, coffee-brown portfolio built with plain HTML and CSS. Responsive, keyboard accessible, and ready for GitHub Pages. The complete webpage is in `index.html`, with all CSS inline. No installation, build step, JavaScript, or external images required. Google Fonts supplies DM Sans and DM Serif Display; local fallback fonts keep the page readable offline.

## Preview

Open `index.html` directly in your browser, or run this command from the repository directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Commit these files to your repository. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select your branch and **/ (root)**, then save.

For the existing `VincentNgo12/VincentNgo` repository, the project URL will be `https://vincentngo12.github.io/VincentNgo/` once Pages is enabled and deployment completes. All local asset paths are relative, so both project and user Pages sites work.

## Make it yours

- `index.html`: the entire website, including typography, colors, responsive and print styles, elevator pitch, featured case studies, work list, biography, and contact links.
- The earlier `styles.css` and `assets/favicon.svg` are not used by this single-file version.
- `.nojekyll`: serves the files directly through GitHub Pages.

The page works offline. The project, résumé, GitHub, LinkedIn, and email links open their respective external destinations when used.
